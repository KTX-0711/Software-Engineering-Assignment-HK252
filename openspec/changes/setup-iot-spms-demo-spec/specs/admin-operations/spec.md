## ADDED Requirements

### Requirement: Admin can manage user and staff accounts
The system SHALL provide admin operations for viewing and managing demo accounts and staff roles.

#### Scenario: Admin views account list
- **WHEN** an authenticated admin opens account management
- **THEN** the system shows demo customer, employee, and admin accounts with roles

### Requirement: Admin can manage pricing policy
The system SHALL allow admin users to configure demo pricing policy used by fee calculation.

#### Scenario: Admin updates pricing rule
- **WHEN** an admin changes a demo pricing rule
- **THEN** future fee calculations use the updated rule

### Requirement: Admin can view reports and logs
The system SHALL expose demo reports and logs for parking sessions, payments, and operator actions.

#### Scenario: Admin reviews parking activity report
- **WHEN** an admin opens reports
- **THEN** the system shows parking session and payment data generated by demo flows

### Requirement: Staff can monitor IoT devices
The system SHALL allow staff/admin users to inspect IoT device state, battery level, and fault status.

#### Scenario: Staff sees faulty sensor
- **WHEN** sensor `SENS_A02` is in `DATAERROR`
- **THEN** the monitoring view shows the device status and affected parking spot

### Requirement: Admin operations read from JSON file storage
The system SHALL retrieve account, pricing, log, and report data from static JSON files.

#### Scenario: Admin views logs from JSON
- **WHEN** an admin opens the logs view
- **THEN** the system reads and displays entries from `logs.json` without database queries
